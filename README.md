# 小米 MiMo API Token 消耗追踪器

<p align="center">
  <img src="https://img.shields.io/badge/Platform-Windows-blue?style=flat-square" alt="Platform">

</p>

一个用于精确追踪小米 MiMo 平台 API Token 消耗的桌面工具。通过爬取控制台数据，计算差值来获取特定操作的 Token 使用量。

---

## 功能特性

- 🎯 **精确测量** - 通过差值计算，精确获取单次或批量操作的 Token 消耗
- 📊 **历史记录** - 自动保存所有测量记录，支持备注和导出
- ⚡ **一键测量** - 快速完成单次测量，无需手动操作
- 🖥️ **图形界面** - 简洁易用的 tkinter 界面
- 🔄 **自动刷新** - 结束记录时自动刷新页面获取最新数据

---

## 工作原理

```
┌─────────────────────────────────────────────────────────────┐
│                    Token 消耗追踪流程                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   开始记录                              结束记录             │
│      │                                    │                 │
│      ▼                                    ▼                 │
│  ┌────────┐                          ┌────────┐            │
│  │爬取初始│                          │刷新页面│            │
│  │Token值 │                          │获取新值│            │
│  └────┬───┘                          └────┬───┘            │
│       │                                    │                 │
│       │         ┌────────────┐             │                 │
│       └────────►│ 计算差值   │◄────────────┘                 │
│                 │ 消耗=新值-旧值│                             │
│                 └─────┬──────┘                              │
│                       │                                     │
│                       ▼                                     │
│              ┌────────────────┐                             │
│              │  显示消耗结果  │                             │
│              │  保存到记录    │                             │
│              └────────────────┘                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**核心逻辑：**
1. **开始记录** → 通过 CDP 协议连接 Edge 浏览器，爬取 MiMo 控制台页面的 Token 总消耗数值
2. **结束记录** → 刷新控制台页面，等待加载完成后爬取最新的 Token 总消耗数值
3. **计算差值** → `本次消耗 = 结束时总消耗 - 开始时总消耗`

## 安装步骤

### 1. 安装 Python

如果尚未安装 Python，请从官网下载并安装：
- 下载地址：https://www.python.org/downloads/
- 安装时请勾选 "Add Python to PATH"

### 2. 安装 Playwright

打开命令提示符或 PowerShell，执行：

```bash
# 安装 Playwright
pip install playwright

# 安装浏览器驱动
playwright install chromium
```

### 3. 登录 MiMo 平台

使用 Edge 浏览器访问 https://platform.xiaomimimo.com 并登录你的账号。

**重要：必须保持登录状态，程序才能正常读取数据。**

## 使用方法

### 方法一：双击运行（推荐）

直接双击 `run.bat` 文件，程序会自动：
1. 启动 Edge 浏览器并开启远程调试端口
2. 打开 MiMo 控制台页面
3. 启动 Token 追踪器界面

### 方法二：手动启动

**步骤 1：启动 Edge 浏览器**

```bash
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222
```

**步骤 2：打开 MiMo 控制台**

在 Edge 中访问：
```
https://platform.xiaomimimo.com/console/plan-manage
```

**步骤 3：运行追踪器**

```bash
python token_tracker.py
```

### 按钮功能

| 按钮 | 功能 |
|------|------|
| **开始记录** | 读取当前页面的 Token 总消耗值作为起点 |
| **结束记录** | 刷新页面获取最新总消耗值，计算本次消耗 |
| **一键记录** | 自动完成开始+结束记录（适合快速测量） |
| **A+** | 增大历史记录字体 |
| **A-** | 减小历史记录字体 |
| **删除选中** | 删除勾选的历史记录 |

## 历史记录管理

- 所有测量记录自动保存到 `history.json`
- 可以为每条记录添加备注（在右侧输入框输入后点击 ✓）
- 可以勾选记录后点击"删除选中"来清理记录
- 记录按时间倒序显示（最新的在最上面）

### 记录格式

```json
{
  "id": 1780586201063,
  "time": "2026-06-04 23:16:41",
  "start": 721080984,
  "end": 727180284,
  "consumed": 6099300,
  "note": ""
}
```

| 字段 | 说明 |
|------|------|
| id | 记录唯一标识（时间戳） |
| time | 测量时间 |
| start | 开始时 Token 总消耗 |
| end | 结束时 Token 总消耗 |
| consumed | 本次消耗量 |
| note | 用户备注 |

## 常见问题

### Q: 提示"未找到浏览器上下文"怎么办？

**A:** 确保 Edge 浏览器已打开，且带 `--remote-debugging-port=9222` 参数启动。

### Q: 提示"未找到 MiMo 控制台页面"怎么办？

**A:** 确保 Edge 中已打开 `https://platform.xiaomimimo.com/console/plan-manage`

### Q: 读取的数据不准确怎么办？

**A:** 确保在开始和结束记录之间，没有其他页面刷新操作。

### Q: 如何清除所有历史记录？

**A:** 直接删除 `history.json` 文件即可。

### Q: 程序无法启动怎么办？

**A:** 检查是否已正确安装 Python 和 Playwright：
```bash
python --version
pip show playwright
```
