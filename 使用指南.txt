【功能简介】
本工具用于追踪小米 MiMo 平台 API Token 的消耗量。
通过爬取控制台页面的 Token 总消耗数据，计算差值来精确获取特定操作的 Token 消耗。


【环境要求】
1. Windows 操作系统
2. Python 3.7+
3. Microsoft Edge 浏览器
4. Playwright 库 (pip install playwright)
5. 已登录小米 MiMo 平台账号


【安装步骤】
1. 安装 Python（如尚未安装）
   下载地址：https://www.python.org/downloads/

2. 安装 Playwright
   打开命令行，执行：
   pip install playwright
   playwright install chromium

3. 登录 MiMo 平台
   用 Edge 浏览器打开 https://platform.xiaomimimo.com
   登录你的账号（必须保持登录状态）


【使用方法】

方法一：双击运行
  直接双击 run.bat 文件即可启动程序

方法二：手动启动
  1. 先启动 Edge 浏览器（带远程调试端口）：
     msedge.exe --remote-debugging-port=9222

  2. 在 Edge 中打开 MiMo 控制台：
     https://platform.xiaomimimo.com/console/plan-manage

  3. 运行 Python 脚本：
     python token_tracker.py

【典型使用场景】

场景一：测量单次 API 调用消耗
  1. 点击"开始记录"
  2. 执行你的 API 调用
  3. 点击"结束记录"
  4. 查看消耗量

场景二：测量批量操作消耗
  1. 点击"开始记录"
  2. 执行所有批量操作
  3. 点击"结束记录"
  4. 查看总消耗量

场景三：快速测量
  直接点击"一键记录"，自动完成测量


【历史记录】

- 所有测量记录自动保存到 history.json
- 可以为每条记录添加备注（在右侧输入框输入后点击 ✓）
- 可以勾选记录后点击"删除选中"来清理记录
- 记录按时间倒序显示（最新的在最上面）


【工作原理】

1. 开始记录时：
   程序通过 CDP 协议连接 Edge 浏览器
   读取 MiMo 控制台页面上的 Token 总消耗数值

2. 结束记录时：
   程序刷新 MiMo 控制台页面
   等待页面加载完成
   读取最新的 Token 总消耗数值

3. 计算差值：
   本次消耗 = 结束时总消耗 - 开始时总消耗


【常见问题】

Q: 提示"未找到浏览器上下文"怎么办？
A: 确保 Edge 浏览器已打开，且带 --remote-debugging-port=9222 参数启动

Q: 提示"未找到 MiMo 控制台页面"怎么办？
A: 确保 Edge 中已打开 https://platform.xiaomimimo.com/console/plan-manage

Q: 读取的数据不准确怎么办？
A: 确保在开始和结束记录之间，没有其他页面刷新操作

Q: 如何清除所有历史记录？
A: 直接删除 history.json 文件即可
